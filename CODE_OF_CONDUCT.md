# Code of Conduct

## Our standard

We want this project to be a useful, evidence-based and respectful open-source
project.

Contributors and maintainers are expected to:

- discuss ideas and disagreements professionally;
- focus criticism on code, evidence, sources and outcomes rather than people;
- welcome good-faith questions and corrections;
- respect privacy and avoid posting unnecessary personal employment information;
- use official primary sources when making claims about legislation or public
  holiday rules;
- avoid harassment, discrimination, threats, intimidation and personal attacks.

## Scope

This code of conduct applies to repository issues, pull requests, discussions,
reviews and other project-managed community spaces.

## Enforcement

Maintainers may edit, hide, lock or remove content, reject contributions, or
restrict participation when conduct materially undermines a safe and productive
project environment.

For security vulnerabilities, follow `SECURITY.md` rather than posting details
in a public issue.

For calculation errors or legal-data updates, use the repository's issue
templates and avoid including names, employer details, child names, or other
unnecessary identifying information.
